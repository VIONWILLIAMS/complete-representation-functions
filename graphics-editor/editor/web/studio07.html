使用说明
已有案例一直在
左侧直接选择红绿灯街景、湖畔、实拍水果和全部0.6场景。它们保留各自的对象编辑、相机、视频、像素检查与导出能力。切换案例时会保存本页状态。
描述、搜索、生成
选择“生成新图片”并描述目标。模型服务返回场景程序后，由本地渲染器求值。参考列表只显示本次实际搜索返回的证据。
对话修改与画面检查
“修改当前画面”在当前表示上编辑。“检查当前画面”把实际画布送交模型分析；是否支持图像检查取决于已连接模型。“检查并改进”提交实际画面，并生成反馈候选。新图默认执行一轮可关闭的画面反馈，候选完成渲染后才替换初稿；可对照“初稿 / 反馈后”。每次修改后可导出独立的场景程序。
质量与真实性
照片观测的像素回放、基于单图的空间假设和原生程序生成分别标明。界面不将程序通过校验等同于照片写实，不将模型自评当作独立质量证明。
保存
本页对话和各场景草稿尽力保存在当前浏览器中。请导出重要场景 JSON 作为可移植副本。API 密钥仅由服务端保存。
