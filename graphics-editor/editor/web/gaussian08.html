CRF 0.8

这一版如何工作

真正的高斯拟合

参考照片经过数值拟合，转换为有位置、尺度、方向和颜色系数的二维高斯函数。画布只读取这些参数并计算像素；不把源 RGB 数组当作新图重新播放。

一个共同的场景程序

观测重建、对象编辑、DeepSeek 编排使用同一个资产与场景接口。移动、缩放、色相、曝光和透明度均可直接修改，也可导出 JSON 供其他模型操作。

生成质量的边界

这里的生成采用已拟合视觉资产的组合与修改。高斯表示提供可计算的外观，并不凭空提供所有物体的知识。参考照片里没有出现的表面、真实三维和任意新视角并未因此被解决。

反馈不会自动等于变好

模型可以检查实际画布并提出修改候选。最多三轮，保留上一版与候选供你比较，由你决定采用；模型自评不作为照片质量分数。
