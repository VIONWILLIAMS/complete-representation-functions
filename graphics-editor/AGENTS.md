先遵守仓库根目录 `AGENTS.md` 的数学域、核心 DSL 和证据规则，再阅读：

## 现行工程与研究约束

1. **兼容。**保留原 17 个入口、旧 URL、公开资源、历史 schema 和工程重放。保留现有对象函数实验；旧资产不得悄悄覆盖。历史浏览器发布包 250 MiB 门槛继续遵守，云 GPU 的大型权重、检查点和函数资产使用现有受控资产存储及内容哈希引用，不塞入浏览器静态包。
2. **原生表示。**采用 CRF 场景程序、覆盖/颜色/关系/成像算子及明确的对象函数。允许本轮计划中的对象层级、局部深度/法线、材质与原生空间查询研究；最终像素由声明的 CRF 内核计算。不转向 Blender 或手工网格产品流水线替代本项目产图。新增编辑器 schema / Operator IR 不自动构成新 CRF 数学域或核心 DSL 关键词。
3. **对象局部训练范围。**本轮已纳入逐对象、逐观察或逐资产的小网络/特征参数训练，旧文件笼统的“禁止模型训练”在这个范围内作明确调整。记录输入、目标、权重、参数数、成本及适用域。基础语言/视觉模型保持冻结，不训练跨场景共享基础模型。冻结对象资产可以复用。单纯调权重属于参数优化，通常是 L0，不能计为 L2 RSI。
4. **像素来源。**禁止隐藏源 RGB 贴回、来源不明的残差整图或外部完整成图。观察、估计、合成与未知分别标记。合法外观重建需明确标签，不把坐标到 RGB 的记忆或断源图重放当成几何、材质、光照分离的证明。
5. **几何与光学边界。**固定视角/有限视角 2.5D 不保证背面、离屏、折射或完整间接光。空间查询至少区分 hit/miss/unknown；unknown 不能当 miss。需要空间信息的效果必须等相关查询、介质和独立积分检查成立。材质本征场不暗中以光源/帧号/相机像素坐标绕过成像语义。
6. **GPU 与预算。**先迁移真实计算，再剖析优化。以可见显存 bytes 和有效工作集调度，默认整卡 guard 至少 10%，未入账峰值还需扩大；8% guard 仅可在独立压力校准后采用。allocated 包含在 reserved 中，两者不相加。一个主要 GPU 所有者共享资产；禁止填充无用张量、复制模型或只为占用显存扩任务。保持逻辑批和总样本预算，先减少并发处理量应对内存压力。原 `V11-T19` 的 WebGPU 子项独立追踪；新增 CUDA 后端不自动完成或撤销该要求。
7. **证明。**区分形式证明、有限实例检查、数值测量、模型意见与人工评价。工具不可用、超时或证据陈旧时保留真实状态；Lean 定理声明语义范围与可信基础，拒绝 `sorry` 和未允许公理。新增 CUDA/浮点/采样路径不自动继承旧证明。
8. **RSI。**L0 参数、L1 管线、L2 可执行算法结构分别记录。人工升级与算力扩容不是系统自主发现。提议须通过类型、作用域、预算和有界执行检查。候选不能修改自身合同、CPU 参考、验证器、封存集、晋升规则或成本账本。保留失败、拒绝、未知、回退和后续新任务真正继承的证据。
9. **固定合同。**原 `quality12.json` 的 800×531 观察、PSNR/SSIM/MAE、ROI 和 4M 像素/200M 支持访问预算保持。新增 `quality13.json` 的三个源尺寸、摘要、ROI、全图/尾部误差及拟合预算也保持；CPU同函数数对照不能改称GPU等时收益。GPU 原生 4K 另建版本化合同；不能放宽旧合同或重命名失败为通过。CPU/GPU 误差按新旧各自支持域冻结；不承诺跨后端 bitwise 恒等。
10. **编辑依赖与实际流程。**阴影/反射/间接光可能扩展影响域；用户冻结区与物理传播冲突时准确报告，不能绕过已批准约束。GUI、Harness、Kernel 使用同一场景语义。真实模型调用、任务取消/恢复、保存/重开、原生导出均需实际验证；没有接通的服务不得返回模拟成功。

## 命名、执行与验收

原 1.1 编号统一引用为 `V11-M0`–`V11-M5`、`V11-T00`–`V11-T26`；GPU 新阶段为 `GPU-M0`–`GPU-M6`。历史原文中的裸编号属于该历史计划，不能跨体系解释。`V11-M3` 是 RSI 开发/选择集试用，`V11-M5` 是原正式封存；新 `GPU-M5` 是空间光传输，GPU 正式封存与发布检查在 `GPU-M6`。

沿活动任务依赖持续推进已授权开发。先记录分支、提交、启动与基线，再写实现；独立模块可并行，并汇合到真实编辑器。每阶段保存命令、环境、输入/合同/输出摘要、失败和可重放证据。保留用户未提交修改，使用隔离工作目录。实现状态与验证状态分别记录；规划 JSON 不能越过根目录 claim 规则把数学声明标为 verified。

外部发布、远端写入和付费调用遵循实际会话授权。用户已有 GPU 不等于有无限后台计算预算；计划中的采样、2 小时稳定性和容量实验是待执行验收要求，不是本次已运行结果或新增云资源购买许可。缺少凭证、GPU 连接或资料时记录具体阻塞，继续可独立完成的代码，不虚构结果，不增加无必要的阶段确认。
