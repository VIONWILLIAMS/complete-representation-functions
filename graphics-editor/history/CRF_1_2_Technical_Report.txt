下一步：从一张新照片得到可编辑程序
交付给用户的操作是上传左侧光照的一张桌面实拍，说“把它压矮一点，保留那个标志性部件”，再说“让光从左移到右”。工作台返回可查看的部件程序、修改前后对照、第 2 秒 PNG 和 5 秒 MP4。建议先限定在固定机位、简单桌面、单个有明显部件的不透明物体。首个开发样本可以使用一只带不对称色带的杯子；另留一件未参与开发的物体复测。
| 开发顺序
| 具体完成什么
| 怎样验收（建议标准）
| ① 先接通工作台
| 把现有作者、校验器和导出器接到同一条任务流程。用一句新描述从空白创建，再连续两轮编辑

| ② 接入一张照片
| 从可见轮廓、标志性部件、桌面接触位置及初始光向生成同协议程序。标记哪些来自观察、哪些是估计
| 先验编辑前的重建。将程序轮廓与独立人工标注比较，建议交并比至少 0.90，即重合面积占两块轮廓合并面积的九成；在 640 × 400 统一坐标下，接触位置误差建议不超过 3 像素。单独记录标志性部件的位置和外观，防止一个相似轮廓就过关
| ③ 分开验形变和换光
| 从初始程序分出两条比较。第一条只改高度，第二条保持原高度、只改光。最后用压矮版导出完整短片
| 形变分支核对部件、接触点和保护区逐像素零漂移。换光分支对照封存的右照实拍。导出继续要求第 2 秒 PNG 与编码前对应帧零差异
右照实拍是这里最重要的新增验收。 同一物体、同一位置、同一机位，锁定曝光和白平衡，各拍一张左右侧光照片。只有左照进入系统；右照留给验收。让原高度程序预测右照，与“保持原来左光”的对照比较。在预先标记的物体和桌面落影两个区域，分别计算与右照实拍的平均颜色误差，两区都应改善，并报告具体差值。这样即使画面有一块高光在移动，也要对得上这件实物。
上述数字是下一轮建议门槛。先用开发照片校准，冻结后再看陌生物体。重建只从声明的场景程序产生最终像素，原图仅作为观察与评价依据；记录背景补全的推断区域。开发物体、封存物体、保护区、阈值和失败样本分别留档。先交付这条照片闭环，真实三维新视角 A/B 继续排在其后。

You write a fixed-camera scene program. Answer with one JSON object, without commentary.

The full program contains exactly these six fields:
- `version` is integer 1. `title` is a short descriptive string.
- `scaleY` is a positive vertical factor about the tabletop. Start at 1.
- `light` is {"keys":[[time_in_seconds,x_direction], ...]}. Time begins at 0 and increases strictly.
Left is -1 and right is +1. Interpolate at intermediate times. Initially use [[0,-1]].
- `materials` maps short material IDs to {"color":"#rrggbb","roughness":0.4}. Roughness ranges
from 0 (glossy) to 1 (matte). Choose colors and roughness for the requested object.
- `parts` is a list, painted **back to front**. Each part has its own `id`, an existing
`material` ID, and one of the exact shapes below. The canvas is 640×400; the origin is at
screen (320,300), x goes right, local y goes UP from the tabletop. Model your object
in these pixel units: e.g. a 160-unit height will occupy 160 screen pixels at scaleY=1.
Leave comfortable space within the canvas. Nodes may intentionally overlap.
Geometry vocabulary:
- `profile` has fields `id, material, kind, cx, levels`. Levels are at least two [y,radius]
pairs from bottom to top with strictly increasing y. The width is twice the radius, centered
at cx. This primitive renders the exterior side with computed normals. Define any upward-facing
surface or opening using separate projected ellipses. Put the lowest support at y=0.
- `ellipse` has fields `id, material, kind, cx, cy, rx, ry`. It is a filled, shaded oval

- `tube` has fields `id, material, kind, path, radius`. Draw a smooth rounded stroke along at
least two [x,y] points with positive radius. Build any connected parts so they overlap at attachment sites.
Use 1–64 parts, 1–48 materials and at most 128 points per primitive. Geometric coordinates
are between -640 and +640, individual radii at most 400. IDs have 1–80 characters.

merge patch. The host applies it to the same preceding scene. Never regenerate its parts or materials.

"""Render and measure an authored three-step scene. Run with Python, NumPy, Pillow and ffmpeg."""
import argparse
import hashlib
import json
import subprocess
from pathlib import Path
import numpy as np
from PIL import Image
from renderer import Renderer
from author import parse, validate
FPS = 24
COUNT = 120
STILL_INDEX = 48
SIZE = (640, 400)
ROOT = Path(__file__).resolve().parent
def digest(data):
return hashlib.sha256(data).hexdigest()
def load(path):
return validate(parse(path.read_text(encoding="utf-8")))
def save_json(path, obj):
path.write_text(json.dumps(obj, ensure_ascii=False, indent=2, allow_nan=False) + "\n", encoding="utf-8")
def image(path, rgb):
Image.fromarray(rgb).save(path)
def centroid_x(channel):
mass = channel.astype(np.float64).sum(axis=0)
if mass.sum() <= 0:
raise ValueError("empty lighting channel")
return float(np.dot(np.arange(len(mass)), mass) / mass.sum())
def height_and_bottom(ids):
ys = np.where(ids > 0)[0]
return int(ys.max() - ys.min() + 1), int(ys.max())
def probe_movie(path):
raw = subprocess.check_output(["ffprobe", "-v", "error", "-select_streams", "v:0", "-show_frames",
"-show_entries", "stream=codec_name,width,height,avg_frame_rate:frame=best_effort_timestamp_time:format=duration",
"-of", "json", str(path)])
probe = json.loads(raw)
stream = probe["streams"][0]
pts = [float(frame["best_effort_timestamp_time"]) for frame in probe["frames"]]
return {**stream, "frames": len(pts), "duration": float(probe["format"]["duration"]),
"ptsMatch": len(pts) == COUNT and all(abs(value-i/FPS) < 0.000001 for i, value in enumerate(pts))}
def render_movie(scene, out):
animation = Renderer(scene)
path = out / "light.mp4"
args = ["ffmpeg", "-v", "error", "-y", "-f", "rawvideo", "-pix_fmt", "rgb24", "-s", "640x400",
"-r", str(FPS), "-i", "pipe:0", "-an", "-c:v", "libx264", "-crf", "17", "-pix_fmt", "yuv420p",
"-movflags", "+faststart", str(path)]
hashes = []
with subprocess.Popen(args, stdin=subprocess.PIPE) as encoder:
for i in range(COUNT):
frame = animation.frame(i / FPS)
raw = frame.tobytes()
hashes.append(digest(raw))
encoder.stdin.write(raw)
if i == STILL_INDEX:
reference = frame.copy()
if i == COUNT - 1:
image(out / "right.png", frame)
encoder.stdin.close()
if encoder.wait():
raise RuntimeError("ffmpeg encoding failed")
# Reload the saved scene and seek independently of the frame-sequence renderer.
still = Renderer(load(out.parent / "03" / "scene.json")).frame(STILL_INDEX / FPS)
image(out / "second-2.png", still)
stored = np.asarray(Image.open(out / "second-2.png").convert("RGB"))
decoded = subprocess.check_output(["ffmpeg", "-v", "error", "-i", str(path), "-vf", r"select=eq(n\,48)",
"-frames:v", "1", "-f", "rawvideo", "-pix_fmt", "rgb24", "pipe:1"])
yuv_delta = np.abs(np.frombuffer(decoded, np.uint8).reshape(still.shape).astype(np.int16) - stored)
save_json(out / "frame-hashes.json", hashes)

"stillRawSHA256": digest(stored.tobytes()), "videoRawSHA256AtIndex": hashes[STILL_INDEX],
"differentPixelsBeforeEncoding": int(np.any(stored != reference, axis=2).sum()),
"decodedMeanAbsoluteChannelError": round(float(yuv_delta.mean()), 4),
"videoSHA256": digest(path.read_bytes())}
def protected_masks(coverage, short_coverage, shadow, short_shadow):
y, x = np.indices(coverage.shape)
# Fixed camera and predeclared working envelope; independent of RGB differences.
possible_subject = (x >= 105) & (x <= 550) & (y >= 55) & (y <= 320)
possible_shadow = (y >= 230) & (y <= 370)
fixed = ~(possible_subject | possible_shadow)
# Coverage includes every antialiasing subsample at the current resolution.
background = (coverage == 0) & (short_coverage == 0) & (shadow == 0) & (short_shadow == 0)
return fixed, background

shade_x = [round(centroid_x(d["shadow"] * (d["id"] == 0)), 3) for d in (left, right)]

"lightOnlyEdit": {**short, "light": timed["light"]} == timed and np.array_equal(b, c),
"visiblyShorter": heights[1] < heights[0]*.94 and heights[1] >= heights[0]*.5,
"supportStays": abs(bottoms[1]-bottoms[0]) <= 3 and abs(bottoms[0]-300) <= 15,
"fixedProtectedRegion": int(fmask.sum()) >= 60000 and not np.any(changed & fmask),
"backgroundBeyondGeometryAndShadow": int(bgmask.sum()) >= 60000 and not np.any(changed & bgmask),
"stableShapeAndMaterialAcrossLight": all(np.array_equal(left[k], right[k]) for k in ("id", "albedo", "normal")),
"highlightMovesRight": spec_x[1]-spec_x[0] >= 3, "shadowMovesLeft": shade_x[0]-shade_x[1] >= 3,
}
metrics = {"heightsPx": heights, "footRow": bottoms, "fixedProtectedPixels": int(fmask.sum()),
"fixedProtectedChangedPixels": int((changed & fmask).sum()), "protectedPixels": int(bgmask.sum()),
"protectedChangedPixels": int((changed & bgmask).sum()), "changedPixels": int(changed.sum()),
"highlightCentroidX": spec_x, "visibleShadowCentroidX": shade_x}
if cup_check:

and movie["width"] == 640 and movie["height"] == 400 and movie["avg_frame_rate"] == "24/1"
and movie["duration"] == 5.0 and movie["ptsMatch"] and movie["uniqueRawFrames"] >= 60)

"programFilesSHA256": program_hash, "rendererSHA256": digest((ROOT/"renderer.py").read_bytes())}
save_json(case / "evidence.json", report)

# CRF 1.2 固定镜头场景程序实验
打开 [实验画廊](../reports/v12/index.html) 可以播放两段视频，查看三步画面对照并下载场景原稿。工程从本地 1.1 提交 `9c6ecd6fc56f` 分出独立实验分支。
两次创作各由一个独立上下文的 Codex 作者完成。每个作者依次收到创作、压矮和移动光源三条指令。作者自行选择部件、形状、位置和材料。内核提供轮廓、椭圆和管状曲线三个通用绘图操作，以及固定的木桌、背景、相机和光照计算。每次压矮围绕桌面修改整体高度，每次换光只添加光源轨迹。渲染和测量都在本地运行。此处验证两个固定视角下的程序场景，照片级质感和真实三维机械运动需要另行验证。
## 查看证据
- 两组实验的 `author/dispatch.json` 记录实际派发给模型的指令，`author/*-response.json` 是未修改的模型输出。每轮 `01/`、`02/`、`03/` 都有经检查的场景程序、重放提示及收据。
- [冻结记录](../reports/v12/pre-holdout-freeze.json) 包含陶杯通过时的渲染器、作者协议、通用判定器和首轮证据摘要。之后独立出题人选了红色订书机。第二个作者只读取通用绘图协议。每个物体特有的判定均位于下游，与生成程序分开。
- 同一份动画程序按时间生成 120 帧。独立重载程序定位第 2 秒并导出 PNG，逐像素核对送入编码器的第 48 帧（从 0 编号）。有损 H.264 解码误差另列于 `evidence.json`。
- [本地模型入口实测](../reports/v12/local-provider-check/receipt.json) 记录额外一次 Qwen3-4B 离线调用。它接收最初的陶杯程序，生成了高度系数 0.78 的编辑。画廊两套程序的创作来源见各轮 Codex 收据。

def _longest_run(bits):
padded = np.pad(np.asarray(bits, bool), 1)
changes = np.flatnonzero(padded[1:] != padded[:-1])
return int(np.max(changes[1::2] - changes[::2], initial=0))
def check_stapler(scene, rgb, ids):
"""Uses the object silhouette, rendered colors and material assignments only."""
mask = np.asarray(ids) != 0
ys, xs = np.where(mask)
if not ys.size:
return {"passed": False, "reason": "empty silhouette"}
region = np.s_[ys.min():ys.max()+1, xs.min():xs.max()+1]
silhouette = mask[region]
index = ids[region]
color = np.asarray(rgb[region], np.int16)
h, w = silhouette.shape
intrinsic = np.zeros((len(scene["parts"]) + 1, 3), dtype=np.int16)
for i, part in enumerate(scene["parts"], 1):
intrinsic[i] = tuple(bytes.fromhex(scene["materials"][part["material"]]["color"][1:]))
pigment = intrinsic[index]
red_mat = (pigment[..., 0] > pigment[..., 1] + 40) & (pigment[..., 0] > pigment[..., 2] + 35)
red = red_mat & (color[..., 0] > color[..., 1] + 20) & (color[..., 0] > color[..., 2] + 18)
neutral_mat = (np.ptp(pigment, axis=2) <= 55) & (pigment.mean(axis=2) >= 105)
silver = silhouette & neutral_mat & (np.ptp(color, axis=2) <= 65) & (color.mean(axis=2) >= 65)
# Only count exterior air with a horizontal line of sight out of the nose.
air_to_right = ~np.logical_or.accumulate(silhouette[:, ::-1], axis=1)[:, ::-1]
solid_above = np.logical_or.accumulate(silhouette, axis=0)
solid_below = np.logical_or.accumulate(silhouette[::-1], axis=0)[::-1]
through_slot = air_to_right & solid_above & solid_below
gap_heights = np.asarray([_longest_run(through_slot[:, x]) for x in range(w)])
left = slice(round(0.04 * w), max(2, round(0.38 * w)))
right = slice(round(0.52 * w), max(2, round(0.96 * w)))
viable_gap = (gap_heights >= max(2, 0.018 * h)) & (gap_heights <= 0.50 * h)
front_gap_run = _longest_run(viable_gap[right])
# Rear connection requires actual material continuously joining upper/lower
# levels over several adjacent columns on the left. A detached upper piece
# with a nearby tall upright on the bottom alone is excluded by the red test.
rear_joint = np.zeros(w, dtype=bool)
for x in range(left.start, left.stop):
line = np.pad(silhouette[:, x], 1)
edges = np.flatnonzero(line[1:] != line[:-1])
for top, bottom in zip(edges[::2], edges[1::2]):
if bottom - top >= 0.42 * h and red[top:bottom, x].any() and bottom > 0.60 * h:
rear_joint[x] = True
break
rear_joint_run = _longest_run(rear_joint)
# Three ordered pixel layers in the same column: upper red shell, pale
# neutral magazine, then the nose opening. Excludes silver foot or hinge pin.
red_above = np.logical_or.accumulate(red, axis=0)
gap_below = np.logical_or.accumulate(through_slot[::-1], axis=0)[::-1]
between = silver & red_above & gap_below
magazine_cols = between.any(axis=0)
magazine_run = _longest_run(magazine_cols)
upper = red[:max(1, round(0.58*h))]
top_red_run = _longest_run(upper.any(axis=0))
checks = {
"side_profile_wider_than_high": w >= 1.35 * h,
"visible_red_upper_handle": top_red_run >= 0.32 * w and int(upper.sum()) >= 100,
"closed_rear_joint_on_left": rear_joint_run >= max(3, 0.025 * w),
"narrow_right_opening": front_gap_run >= max(5, 0.10 * w),
"silver_magazine_below_handle_above_slot": magazine_run >= max(5, 0.10 * w),
}
return {
"passed": all(checks.values()), "checks": checks,
"object_width_px": w, "object_height_px": h,
"longest_red_upper_run_px": top_red_run, "rear_joint_contiguous_width_px": rear_joint_run,
"front_gap_contiguous_width_px": front_gap_run,
"median_gap_height_over_front_columns_px": (
float(np.median(gap_heights[right][viable_gap[right]])) if viable_gap[right].any() else None),
"ordered_silver_strip_width_px": magazine_run, "ordered_silver_strip_area_px": int(between.sum()),
"scope": "Pixel arrangement in fixed side view. Metallic composition and hinge mechanics require separate evidence.",
}
def main(case):
from renderer import Renderer
from run import load, save_json
scenes = [load(case / stage / "scene.json") for stage in ("01", "02", "03")]
stages = {}
for scene, (label, filename, time) in zip(scenes, (
("initial", "initial.png", 0), ("short", "short.png", 0), ("relit", "right.png", 119/24)
)):
renderer = Renderer(scene)
rgb = np.asarray(Image.open(case / "renders" / filename).convert("RGB"))
measured = check_stapler(scene, rgb, renderer.diagnostics(time)["id"])
measured["replayed_pixels_equal_saved_image"] = bool(np.array_equal(rgb, renderer.frame(time)))
stages[label] = measured
result = {"passed": all(row["passed"] and row["replayed_pixels_equal_saved_image"] for row in stages.values()),
"checkerSHA256": hashlib.sha256(Path(__file__).read_bytes()).hexdigest(), "stages": stages}
save_json(case / "semantic.json", result)
print(json.dumps(result, indent=2))
return result["passed"]
if __name__ == "__main__":
parser = argparse.ArgumentParser(description=__doc__)
parser.add_argument("case", type=Path)
args = parser.parse_args()
raise SystemExit(0 if main(args.case.resolve()) else 1)
