# D×L×M Runtime

D×L×M is the CRF runtime coordinate system.

- D: Domain.
- L: Layer.
- M: Manifestation.

The current map uses:

```text
9 domains × 4 layers × 4 manifestations = 144 coordinates
```

M-axis:

1. M1: axioms and mathematical definitions.
2. M2: syntax and type rules.
3. M3: concrete instances.
4. M4: runtime execution or physical rendering.

Use D×L×M to locate errors at the right boundary instead of treating every runtime failure as a theoretical failure.
