# Domain Admission

The Domain Admission Axiom:

```text
D is in the CRF core domain set iff there exists a mathematical theory T
that proves completeness of basis B and closure of operations Ops over D,
and F_D can be constructed from B and Ops.
```

Operational checks:

1. Type independence.
2. Closed output type.
3. Theorem-backed basis and operations.
4. Not reducible to existing CRF domains.

Rejected candidates should be classified as:

- operation
- validator
- observer
- combination pattern
- open candidate
