# BDI Layer

BDI is a horizontal intent semantics layer above CRF domains.

It is not D10.

CRF answers:

```text
Can this domain state be represented?
```

BDI answers:

```text
Which target world should the agent commit to, and when should it reconsider?
```

Canonical chain:

```text
Natural Language -> BDI -> Intent IR -> CRF DSL -> Verified Runtime
```
